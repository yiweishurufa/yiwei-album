# 一维相册 真机发版前 5 分钟冒烟测试

每次发版（或装上新的 android-nightly）前，在真机上按顺序过一遍。每项 20–30 秒，全部打勾再发给别人。
出问题时：设置 → 关于 → 导出诊断日志，连同「哪一步、做了什么、看到什么」一起反馈。

准备：一台连着家里 Wi‑Fi 的手机；飞牛账号；一个 WebDAV 账号（123 云盘或坚果云）；
WebDAV 里有一个含中文/空格文件名的文件夹、一段 iPhone 实况（HEIC + 同名 MOV）、一个 mp4、一个音乐文件夹。

## 0. 安装与启动（30 秒）
- [ ] 覆盖安装能装上（签名没变）；若提示签名冲突，确认这次发版是否有意换签名。
- [ ] 冷启动 1.5 秒内出首屏，没有白屏/闪退。
- [ ] 设置 → 关于 显示的版本号和 CI 编号与发布页一致。

## 1. 飞牛（60 秒）
- [ ] 登录页「搜索局域网里的飞牛」只列出真正的飞牛（不出现整段 192.168.x.x）。
- [ ] 登录后照片页能滚动，缩略图正常，日期分组正确。
- [ ] 切到 4G / 关掉 Wi‑Fi，下拉刷新仍能连上（外网地址自动切换）。

## 2. WebDAV（60 秒）
- [ ] 添加/打开 WebDAV 账号，「测试连接」成功；错误密码给出「用户名或密码错误」。
- [ ] 照片页能加载，中文和空格文件名的照片能显示、能打开大图。
- [ ] 扫描中切到别的页面再回来，进度继续而不是重新开始。
- [ ] 公网 http 地址添加时有「密码将以明文发出」提醒。

## 3. 照片（45 秒）
- [ ] 大图左右滑、双击放大、下拉关闭都正常；连续快速滑 20 张不闪退。
- [ ] 长按多选 → 下载到手机，通知栏有进度，相册里能看到。
- [ ] 筛选（全部 / 照片 / 视频 / 实况）切换正常。

## 4. 实况（30 秒）
- [ ] iPhone 实况（HEIC + MOV）在网格上有实况标记，MOV 不再单独出现。
- [ ] 打开后长按/点实况按钮能播放动态部分；没有同名 MOV 的普通照片不受影响、不闪退。
- [ ] 安卓动态照片（MVIMG_/PXL_*.MP.jpg）能播放。

## 5. 视频（45 秒）
- [ ] WebDAV 和飞牛各播一个 mp4：能起播、拖进度、横屏全屏。
- [ ] 播放中按 Home 回桌面再回来，进度还在；播放时 App 不闪退（2026-10-22 回归点）。
- [ ] Media3 放不了的格式（rmvb/wmv）给出「用其他播放器打开」，不闪退。

## 6. 音乐（45 秒）
- [ ] 影音 → 音乐 能扫出 WebDAV 音乐文件夹里的歌，显示标题/歌手/封面。
- [ ] 播放 mp3 和 flac；锁屏和通知栏能暂停、切歌；蓝牙耳机按键有效。
- [ ] 切到后台 1 分钟音乐不中断。

## 7. 更新（30 秒）
- [ ] 设置 → 关于 → 检查更新：已是最新时提示「已是最新版本」；有新版时弹窗显示版本和说明。
- [ ] （有新版时）应用内下载走 ghfast/gh-proxy，下载完成后能拉起安装器；签名不同会明确提示要先卸载，而不是直接失败。

## 8. 收尾（15 秒）
- [ ] 设置 → 关于 → 导出诊断日志能分享出文件，日志里没有密码、token、完整地址。
- [ ] 以上全部通过，把结果（机型 / Android 版本 / CI 编号）记到发版说明里。
