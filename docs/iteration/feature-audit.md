# 功能审计（2026-11-27，1.7.17）

用户 2026-11-27：「对于功能上，也要进行优化。并且更新时要描述更新内容。并且合并重复选项，或者去掉没用功能」。

范围：设置首页与二级页（照片文件夹 / 手机备份、智能整理、AI、后台整理、影音设置、存储空间、高级、账号页）、
各页「⋯」菜单、长按菜单（人物 / 地点 / 相册 / 歌曲 / 影片）、底部面板（大图「⋯」、信息面板）、发现页三区入口。
方法：通读 `ui/Settings.kt`、`ui/Storage.kt`、`ui/HomeDiscover.kt`、`ui/Viewer.kt`、`ui/MovieDetail.kt`（影音设置）、各页菜单；
每个开关查存储键是否真的被读取（`grep` 读方）；每个 Route / ExtScreen 查是否有入口；全仓库扫描「只有定义、没有调用」的函数。

不在本次范围（用户已定）：图库 / 合集结构、影音搜索搜影片、播放器飞牛影视布局。

## 3. 死代码 / 不可达

所有 `Route` 与 `ExtScreen` 都有入口（`Route.Settings` 是底栏 Tab，`MovieSearch` 是影视顶栏放大镜）。
只有定义、没有任何调用的函数（主代码与单测都没用到），**已删除**：

- `DavLib.aiCategories`、`DavThumb.invalidateFinalUrl`、`MovieLib.clearProgress`、`MusicLib.isFav`
- `MusicState.cycleRepeat` / `toggleShuffle`（界面用的是 `repeatTo` / `shuffleTo`）
- `NetEnv.rtt` / `bypassing`、`CloudHttp.jsonBody` / `formBody` / `FORM`、`CloudAccounts.updateIfSaved`
- `NasX.originalDownload` / `albumDownload`、`Skeuo.surfaceBrush`、`Modifier.clickableNoRipple`
- `Diag.export`（D2 合并后没有调用方）

保留未删：`SearchFilter.noAlbum / noTag / noGeo`（与 `KEYS` 一起记录飞牛官方搜索表单的全部筛选键，是接口说明）、`Haptics.reject`（触感词表的一部分）。

## 4. 仍能用、但价值可能偏低（**未删，待用户决定**）

| 功能 | 在哪 | 为什么觉得价值低 |
|---|---|---|
| 系统定时后台整理（开关） | 设置 → 高级 | 关掉 = 回到 1.0.x 的 JobScheduler 行为，只为排障保留；普通用户关了只会让后台整理变差 |
| 界面风格「简洁」 | 设置 → 外观 | 与「玻璃」二选一；12+ 机型玻璃已有降级，简洁主要给低端机省电。保留价值取决于是否有人在用 |
| 使用引导 | 设置 → 关于 | 首次启动已经走过一遍，之后几乎没人再看 |
| 飞牛实况「（未验证）」标记 | 大图顶部日期胶囊 | 飞牛 type-1 实况的视频流映射一直未验证；要么验证后去掉标记，要么不再显示实况入口 |
| 发现 → 工具「文件夹 · 回收站 · 传输」折叠行 | 发现页（飞牛） | 默认收起，点开才有三项；如果三项都常用，折叠只是多点一下 |
