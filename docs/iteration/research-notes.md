结论：
1. fnOS 1.2.1000 缩略图服务新增 DPX / EXR / J2C / J2K 序列帧格式 → 这些文件会进飞牛相册时间线，手机解不了原图。
   一维相册大图原来只对 dng/arw/cr2/nef 停在预览，其它会白白下载原图再解码失败 → 已适配（PreviewOnly，bc8a2e0）。
2. fnOS 1.2.1000 音乐转码「码率数据异常导致播放不完整」是服务端修复；一维相册音乐走文件直连（WebDAV / 飞牛文件管理），不走飞牛音乐转码，无需适配。
   专业视频格式硬件转码（MXF/XAVC/R3D/BRAW/DNxHD）同理只影响飞牛影视转码，一维影视直连播放，不涉及。
3. 飞牛 App v1.37.0 音乐：断网用完整缓存继续播放、弱网切歌失败处理、退出影视后音乐恢复播放（Android）→ 一维可参考：退出影视播放器后恢复被暂停的音乐（候选）。
4. 飞牛独立相册 App 定位「打开即看照片、少操作路径、家人易用」→ 与一维「图库 / 合集」方向一致，继续减少层级。
5. Immich：生日回忆、相似照片、视频高精度拖动、相册排序 / 布局记忆、资源查看器 ⋯ 菜单收纳按钮 → 候选：大图 ⋯ 面板整理、相册排序记忆。
6. 音乐类 App（网易云 / QQ 音乐 / Apple Music）共有「我喜欢」「最近播放」两个固定入口 → 一维音乐缺失，今天实现（A2）。
