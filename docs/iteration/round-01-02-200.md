# 一维相册 200 条优化建议（2026-10-24）

标记：★ 推荐优先　◇ 合并　✂ 删减

## 一、照片浏览（1–25）
1. ★ 时间轴右侧快速滚动条，拖动时显示「2023 年 5 月」气泡
2. ★ 网格双指缩放切换 年 / 月 / 日 / 大图 四级密度
3. 网格列数记忆，按横竖屏分别保存
4. 大图下滑关闭时缩回原缩略图位置（共享元素动画）
5. 大图底部胶片条，可左右快速定位
6. 大图上滑显示信息面板：时间、地点小地图、相机参数、文件路径、大小
7. 实况照片长按播放，带轻微震动
8. 连拍照片折叠成一组，展开选最佳
9. RAW + JPG 同名文件合并显示，角标标注 RAW
10. 截图、录屏、证件、票据自动归类成独立视图
11. 「最近添加」视图，按入库时间排序，区别于拍摄时间
12. 收藏（心形）一键加入，并在首页提供收藏入口
13. 照片星级 1–5 星，可按星级筛选
14. 地图视图：按聚合点展示，缩放后散开
15. 「那年今天」支持左右翻到前后几天
16. 全屏幻灯片：可选间隔、转场、背景音乐
17. 大图支持 HEIF / AVIF / WebP 动图 / GIF 播放
18. 超大全景图平铺解码，缩放不糊
19. 视频缩略图悬停预览（长按网格中的视频，静音播放 3 秒）
20. 按拍摄设备（手机型号、相机）筛选
21. 按文件夹浏览（NAS 原始目录结构）与时间轴一键切换
22. 隐藏照片支持「仅在隐藏相册可见」且不参与回忆、搜索
23. 照片对比：选两张左右或上下滑动对比
24. 大图显示人物框，点头像跳到该人物
25. 首页顶部一行「今天值得看」：回忆、旅行、新识别的人物

## 二、智能整理与搜索（26–50）
26. ★ 搜索合并为一个框：文字、人物、地点、时间、图中文字一起联想
27. ★ 自然语言时间：「去年冬天」「上个月在青岛」
28. 搜索结果按类型分组，顶部可切换「全部 / 人物 / 地点 / 文字」
29. 搜索历史与热门搜索，可一键清空
30. 人物：合并建议卡片「这两个是同一个人吗？」，是 / 否 两键
31. 人物：设置生日后，自动生成「成长时间线」
32. 人物：宠物识别（猫、狗）单独成组
33. 人物：可设封面头像
34. 相似照片：自动推荐保留最清晰、未闭眼的一张
35. 模糊、过曝、误拍照片检测，进入「建议清理」
36. 大视频 / 大文件排行，显示可释放空间
37. 截图过期提醒：30 天前的截图建议清理
38. 智能相册：可自定义规则（人物 + 地点 + 时间段）并自动更新
39. 旅行相册生成封面、标题、路线图
40. 旅行相册支持手动合并、拆分、重命名
41. 节日回忆：春节、中秋、生日等自动成集
42. 场景分类（海边、雪景、美食、夜景）离线识别
43. 图中文字可复制、可点击电话 / 网址
44. 二维码识别，大图上直接打开
45. 证件照智能打码后再分享
46. 整理进度在通知栏显示，可暂停 / 仅充电时进行
47. 整理任务设置「仅 Wi-Fi + 充电 + 夜间」三选项
48. 整理完成后一条汇总通知：新增人物、旅行、可清理空间
49. 识别结果可导出 / 导入，换手机不用重算
50. 多台手机共享识别结果（存回 NAS 一个隐藏目录）

## 三、影音播放（51–85）
51. ★ 播放器首次进入显示一次手势教学浮层
52. ★ 续播提示：「上次看到 32:10，继续播放？」3 秒自动消失
53. 片头片尾跳过：每部剧可设置跳过秒数
54. 倍速 0.5–3.0，倍速记忆按剧保存
55. 字幕样式：字号、颜色、描边、背景、位置
56. 字幕时间轴微调 ±0.1 秒
57. 外挂字幕自动匹配同目录同名 srt / ass
58. 在线字幕搜索（射手 / OpenSubtitles）
59. 音频延迟微调，解决蓝牙耳机不同步
60. 音量增强（超过 100%）与夜间模式动态压缩
61. 画面比例：原始 / 铺满 / 16:9 / 4:3 / 裁边
62. 截图按钮，保存当前帧并可分享
63. 片段截取 GIF / 短视频
64. 锁屏按钮，防误触
65. 进度条缩略图预览（飞牛可用服务器缩略图）
66. 章节标记（mkv chapters）显示在进度条上
67. 播放列表侧栏：剧集一览，标注已看 / 看到哪
68. 定时关闭：本集结束 / 30 / 60 分钟
69. 后台纯音频播放（听剧模式）
70. 投屏：DLNA 与 Chromecast，进度同步
71. 飞牛播放记录双向同步，飞牛影视网页看到哪手机接着看
72. 清晰度「自动」档：根据网速在原画与转码间切换
73. 弱网提示：「当前网速低于码率，建议切换 1080P」
74. 码率 / 网速 / 缓冲实时小浮窗（开发者向，可在详细信息中开启）
75. HDR 视频在不支持的屏幕上做色调映射，避免发灰
76. 杜比视界 / 杜比全景声角标
77. 音轨切换时不黑屏、保持位置
78. 影视首页「继续观看」行置顶
79. 影视海报墙支持按类型、年份、评分筛选
80. 影视详情页显示演员、简介、评分（飞牛刮削数据）
81. 剧集「下一集」预加载前 10 秒，切集秒开
82. 音乐文件独立播放器（封面、歌词、随机）
83. 播放器亮度调节不影响系统亮度，退出恢复
84. 耳机拔出自动暂停
85. 画中画内支持快进 10 秒 / 下一集按钮

## 四、连接、飞牛与 WebDAV（86–110）
86. ★ 首页顶部连接状态胶囊：局域网 / 外网 / 离线，点开看详情
87. ★ 内外网自动切换：在家走局域网，出门走 FN Connect / 域名

96. 批量下载带队列、暂停、失败重试

102. 登录页记住最近 3 个地址
103. 飞牛相册的人物、地点与本地识别结果合并展示
104. 飞牛共享相册浏览与上传
105. 飞牛回收站入口，误删可恢复
106. 支持 Tailscale / ZeroTier 地址自动识别
